# Security Gatekeeper &bull; OWASP & ISO 27001 Auditor

> Catch SQLi, hardcoded tokens, and broken access controls before they hit production.

Compatible with **Claude Code**, **Cursor**, **GitHub Copilot**, **Windsurf**, and **Antigravity**.

---

## ⚡ Quickstart

### 1. Run Automated Scan
\`\`\`bash
node scripts/audit.js .
\`\`\`

### 2. Install to Cursor
\`\`\`bash
cp adapters/cursor/.cursorrules ./.cursorrules
\`\`\`

### 3. Install to Claude Code
\`\`\`bash
cp adapters/claude/CLAUDE.md ./CLAUDE.md
\`\`\`
