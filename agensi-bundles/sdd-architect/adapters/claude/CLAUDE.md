# CLAUDE.md - SDD Architect

## Operational Directives:
- Always practice Spec-Driven Development (SDD).
- When a new feature or refactor is requested, create or read `spec.md` and `plan.md` first.
- Enforce strict parameterization on all SQL queries.
- Ensure all API inputs are validated using schemas (e.g., Zod, Joi).
- Implement features in small, testable increments, checking off tasks sequentially.
