## ⚡ Instant Setup for Any Coding Agent

### 1. Claude Code
Copy `adapters/claude/CLAUDE.md` to the root of your project:
```bash
cp adapters/claude/CLAUDE.md ./CLAUDE.md
```

### 2. Cursor IDE
Copy `adapters/cursor/.cursorrules` or `adapters/cursor/rules/iso-software-quality.mdc` into your `.cursor/rules/` folder:
```bash
cp adapters/cursor/.cursorrules ./.cursorrules
```

### 3. Google Antigravity
Place this directory inside your workspace's `.agent/skills/iso-software-quality/`:
```bash
cp -r . ./.agent/skills/iso-software-quality
```
