# Physics-Based UI Motion & Micro-Interactions Standard

> **Official Marketplace Package** &bull; Distributed via Agensi.io &bull; Developed by Sean Jerve

Design engineering motion standard based on Emil Kowalski principles. Enforces spring physics, zero-sluggishness 60fps transitions, interruptible gestures, and anti-AI slop feel.

---

## ⚡ Instant Setup for Any Coding Agent

### 1. Claude Code
Copy `adapters/claude/CLAUDE.md` to the root of your project:
```bash
cp adapters/claude/CLAUDE.md ./CLAUDE.md
```

### 2. Cursor IDE
Copy `adapters/cursor/.cursorrules` or `adapters/cursor/rules/ui-motion-craft.mdc` into your `.cursor/rules/` folder:
```bash
cp adapters/cursor/.cursorrules ./.cursorrules
```

### 3. Google Antigravity
Place this directory inside your workspace's `.agent/skills/ui-motion-craft/`:
```bash
cp -r . ./.agent/skills/ui-motion-craft
```

### 4. GitHub Copilot
Add to `.github/copilot-instructions.md`.

### 5. Windsurf
Copy to `.windsurfrules`.
